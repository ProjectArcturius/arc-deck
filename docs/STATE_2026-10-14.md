## 七、两条给人坑的教训（都是这一轮踩的）

- **真实验证前先重编 release。** `cargo test` 走 debug、真实场景走 release，两者不会互相更新 ——
  拿旧二进制去跑，看到的「没生效」是假的（与 U16 同一类）。为此白跑两轮。
- **`--worktree` 的 `.git` 指向主仓，而主仓在 workspace 之外** —— 授权级别不是 `full` 时，
  worktree 里的 git 命令全部返回 128。现在派工时会警告，但别依赖它。
