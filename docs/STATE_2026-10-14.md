## 四、跑了什么、没跑什么（一句话版）

**跑过**：真派工 → 真实模型 → 验收通过；取消；`kill -9` 监工 → 1 秒判死 → `cancel` 收孤儿；
`--worktree` 真建分支 + 真提交；一般模式；`effort` 端到端（非法值被运行时拒）。
**没跑过**：在 **Ether 仓**里真派一件活；真实运行时下的**卡死续跑**；macOS；Windows 上的 pid 判死
（那一侧刻意降级为「不知道」，因为开发机装不了 Windows target，写了连编译都验不了）。

## 七、两条给人坑的教训（都是这一轮踩的）

- **真实验证前先重编 release。** `cargo test` 走 debug、真实场景走 release，两者不会互相更新 ——
  拿旧二进制去跑，看到的「没生效」是假的（与 U16 同一类）。为此白跑两轮。
- **`--worktree` 的 `.git` 指向主仓，而主仓在 workspace 之外** —— 授权级别不是 `full` 时，
  worktree 里的 git 命令全部返回 128。现在派工时会警告，但别依赖它。
